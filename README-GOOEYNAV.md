# GooeyNav install guide (Robin)

Extract this zip in the project ROOT (the folder with package.json). It adds/overwrites:

  components/ui/GooeyNav.jsx        (new)
  components/ui/GooeyNav.css        (new)
  components/layout/Navbar.tsx      (replaced)

No npm install needed. Restart `npm run dev`, open the site on a desktop-width window (>= 1024px).
